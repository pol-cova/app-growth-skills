# Changelog

All notable changes to this project will be documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.0] - 2026-09-02

### Added

- Codebase-first product discovery before onboarding recommendations.
- Scope boundaries and structured routing evals.
- Structured answer-quality evals, including a critical codebase-first case.
- Regression-fixture guidance based on observed agent failures.
- Source-quality, transferability, and freshness guidance.
- Android onboarding guidance and a broader Apple platform reference.
- Dependency-free structural validation and GitHub Actions CI.

### Changed

- Replaced the linear evidence hierarchy with evidence types matched to the question.
- Added eligible-randomized-population guidance to prevent post-treatment selection bias.
- Added skill author, license, and `0.2.0` metadata.

## [0.1.0] - 2026-09-02

### Added

- Initial `subscription-onboarding` skill.
- Domain references, onboarding audit template, and adversarial eval cases.
